# Chromack

Chromack is a local Noctalia color tool with Color Picker, Shade, Palette, and Theory tabs.

- Enable **dxle/chromack** in **Settings → Plugins**.
- Add **dxle/chromack:bar** from **Settings → Widgets → Bar** to place the optional bar entry.
- Set the label and glyph on that widget. Its left click opens the panel.
- Set the floating panel position and layer from the plugin settings.

The panel follows Noctalia's active palette. Color state, material and recent swatches, CSS exports, and exported palette TOMLs live in the plugin's data directory.
